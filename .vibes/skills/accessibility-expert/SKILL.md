## Instructions
When the user asks to run an accessibility review or check compliance:
1. Audit custom UI structures for semantic hierarchy and screen reader attributes (e.g., aria-live).
2. Verify text-to-background visual contrast ratios (target minimum 4.5:1).
3. Evaluate font scalability and keyboard-only tabbing flows.
